Selecting by Class
HTML
<p class="message">
Hello
</p>

Java Script
const message = document.getElementByClassName("message")

for example,HTMl:

<p>class="student">Peter</p>

you can  select them with Java Script:

Selecting by tag
const paragraphs = document.getElementByTagName("p")

Modern Selectors
querySelector()
selects the first matching element.
const heading = document.querySelector("h1");

querySelectorAll()
Selects all matching elements.

const buttons = document.querySelectorAll(".btn");

Changing Classes
Instead of applying many styles with java script, add or remove CSS classes.
CSS

}

Java Script
document.getElementById("info")
.classlist.add("highlight");

Remove CLass
document.getElementById("info")
.classlist.remove("highlight")

Toggle class
document.getElementById("info")
.classlist.toggle("highlight");
